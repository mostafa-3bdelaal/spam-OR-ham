# 📧 Spam vs Ham Email Detector

**Spam vs Ham Email Detector** is a simple **Machine Learning** project that classifies emails as **spam** (unwanted) or **ham** (legitimate).  
The project uses **Naive Bayes** with **TF-IDF vectorization** and includes a **Streamlit web interface** for easy testing of new emails.

---

## ⚡ Features

- **Classifies emails** into **spam** or **ham**.  
- **Converts email text** into numerical features using **TF-IDF Vectorizer**.  
- **Simple Streamlit interface** to test any new email quickly.  
- **Saves the trained model** and vectorizer for reuse without retraining.
